# FUTURE_UX_03: CRM / Client Management Dashboard UI

**Future Interns · UI/UX Design Track · Task 3**

A web dashboard prototype for a small agency to track leads, manage clients and stay on top of follow-ups (fictional product: *ClientLoop*).

## Deliverables
| Item | Location |
|---|---|
| Interactive prototype | `index.html` (hash routes: `#overview`, `#pipeline`, `#clients`, `#profile`, `#tasks`) |
| Lead pipeline, client list, client profile, task and follow-up screens | inside the prototype; images in [`screenshots/`](screenshots/) |
| Design rationale (workflow logic, usability choices, agency use cases) | [`DESIGN_RATIONALE.md`](DESIGN_RATIONALE.md) |

## Key features
- Lead tracking and client list management
- Visual lead pipeline with status-based stages (drag and drop works)
- Client profile with engagement status and activity timeline
- Task tracker and follow-up reminders (tick tasks to complete them)

## Run locally
No build step. Open `index.html` in a browser.
